Kotlin browser API

A Kotlin library for working with browser declarations in Kotlin with WasmJs and JS targets.

See [Using in your projects](#using-in-your-projects) for the instructions how to setup a dependency in your project.

## Status

The declarations are now generated from current Web IDL (the [webref](https://github.com/w3c/webref) packages), and
one `webMain` source set serves both Kotlin/JS and Kotlin/Wasm. This release is source-incompatible with 0.5.0 and
earlier, which were generated by dukat from a 2017–2019 snapshot of the specs; see the
[migration guide](docs/migration-guide.md).

## Requirements

* Kotlin `2.5.0` or newer
* Kotlin/JS: the declarations bundled with the Kotlin/JS standard library must be turned off (see below)

## Using in your projects

> Note that the library is experimental, and the API is subject to change.

With Kotlin `2.2.20`–`2.4.x`, use `kotlinx-browser` version `0.5.0`; with older Kotlin versions, version `0.3`.

### Gradle

- Add the Maven Central repository if it is not already there:

```kotlin
repositories {
    mavenCentral()
}
```

- Add the dependency to `webMain` (shared by `js` and `wasmJs`), or to one of the target source sets:
```kotlin
kotlin {
    wasmJs {
        browser()
    }
    
    js {
        browser()
    }
    
    sourceSets {
        webMain {
            dependencies {
                implementation("org.jetbrains.kotlinx:kotlinx-browser:0.6")
            }
        }
    }
}
```

- For Kotlin/JS, turn off `kotlin-dom-api-compat`, which the Kotlin Gradle plugin adds to every JS compilation and
  which declares the same `org.w3c.*` names. In `gradle.properties`:

```properties
kotlin.js.stdlib.dom.api.included=false
```

## Building

The build uses the Kotlin Gradle plugin version pinned in `gradle/libs.versions.toml`; no separate Kotlin installation is
needed. The generator's Web IDL inputs are npm packages pinned in `package-lock.json`; Gradle installs and parses
them with the Node.js that gradle-node-plugin downloads.

To build and run all checks, execute:
```shell
./gradlew check
```

The sources in `src/webMain/generated` are generated; see the [development guide](docs/development.md) before
changing them.
